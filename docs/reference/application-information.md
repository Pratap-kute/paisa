# Application information and logs

Two pages under **More** help when you are checking a running installation.

## About

**More → About** shows the installed Paisa version, license, project credits,
and links to project resources. Include the version when reporting a problem so
maintainers can compare it with the relevant release.

## Logs

**More → Logs** displays the application log with timestamps, levels, messages,
and structured context fields. You can filter by Info, Warning, or Error, search
the displayed records, and refresh the list.

Logs can contain account names, file paths, routes, or other local context.
Remove personal financial information before attaching them to a public issue.
