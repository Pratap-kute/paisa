# Interest Breakdown

The Interest Breakdown view compares interest across your liabilities and shows
the drawdown, repayment, interest, balance, and APR for each account. A timeline
helps you see how those values change over time.

The view is empty when the journal does not contain liability activity. Interest
and APR are only as complete as the postings and metadata in your journal.
