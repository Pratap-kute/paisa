# Development

Start with the [contributor setup guide](setup.md) to install the toolchain and
run Paisa from source (also summarized in [CONTRIBUTING](https://github.com/Pratap-kute/paisa/blob/master/CONTRIBUTING.md)), then use the [testing guide](testing.md) and
[API reference](api.md).

The pages under **Design** are internal maintainer references, not end-user
guides. They record frontend and interface decisions and may change without
notice.
