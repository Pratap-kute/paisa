# Project history and community

Paisa was originally created by **[Anantha Kumaran](https://github.com/ananthakumaran)**
and has grown through contributions from the open-source community. The
`Pratap-kute/paisa` repository continues that work with maintenance,
documentation, and new functionality.

The documentation on this site describes the maintained
[Pratap-kute/paisa](https://github.com/Pratap-kute/paisa) repository. Historical
resources from the original project can still be useful, but may describe a
different revision.
